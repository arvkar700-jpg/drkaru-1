## Katim (formerly KaruScan)

The subscription scanner that used to live in this repository has moved to its own repository and is now called **Katim** (Tok Pisin for "cut it").

- **Use the app:** https://arvkar700-jpg.github.io/katim/
- **Source code:** https://github.com/arvkar700-jpg/katim

Katim finds the AI tools and app subscriptions charging your bank card, shows which ones you don't use, and helps you cancel them. It runs in your browser and can be installed on a phone or tablet. All further changes are made in the Katim repository.
